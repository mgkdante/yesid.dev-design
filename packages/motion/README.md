# @yesid/motion

Shared motion for yesid products: Svelte actions, reduced-motion state and policy, GSAP and Lenis
helpers, generated motion tokens and opt-in CSS. Products own page choreography, scroll narratives,
persisted state and art direction.

## Interface

The root and `./actions` exports provide the shared actions. Policy, generated tokens,
reduced-motion state, device, ticker, GSAP, Lenis and ripple helpers each have their own subpath.
The exact interface is in
[`api-reports/motion.api.md`](https://github.com/mgkdante/yesid.dev-design/blob/v0.30.3/api-reports/motion.api.md).

## Rules

- Safe-always feedback and motion-gated effects follow `policy.ts`; reduced motion does not mean
  disabling every response.
- Every action and helper guards browser access and removes its own listeners.
- Consumers import optional CSS explicitly. The package installs no global CSS.
- `magnetic`, `boop` and `cursorGlow` read duration, easing and color variables from
  `@yesid/tokens/tokens.css` at runtime.
- `src/tokens.ts` is generated by the root token build and is never edited by hand.
- `morphHover` and product scroll scrubs stay in the products.

## GSAP and route transitions

`./utils/gsap` registers ScrollTrigger (`initScrollTriggerConfig`) and SplitText eagerly.
`loadDrawSVG`, `loadMorphSVG` and `loadCustomEase` import and register their plugin on first
call, so an app that never calls one doesn't bundle it.

`./utils/viewTransition` exports `viewTransition` for SvelteKit's `onNavigate`. It crossfades
client navigations with the View Transitions API and skips same-path navigations, browsers
without the API and reduced motion. The crossfade CSS lives in `@yesid/ui/base.css`.

GSAP is third-party software under its own license, not this repository's MIT grant. See
[`NOTICE`](https://github.com/mgkdante/yesid.dev-design/blob/v0.30.3/NOTICE).

## Blueprint scrub

`./utils/blueprintScrub` exports `blueprintScrub(band, trigger = band)`: it draws the blueprint art in
`band` (`.blueprint-bg svg path`) as `trigger` scrolls through the viewport, counting scrolls of
inner scrollers too, redraws when `trigger` resizes, and returns its cleanup. It does nothing under
reduced motion or at 1023px and below, where the art stays fully drawn. `ListingFrame`'s
`onHeaderMount={blueprintScrub}` passes the header and the frame.

## Smooth scroll

`initLenis()` starts Lenis on the window, driven by the GSAP ticker and bridged to ScrollTrigger.
It does nothing under reduced motion or on touch devices. `initLenis({ wrapper, content })`
scrolls an element instead; `content` must wrap the whole scrolling flow so Lenis tracks its
height. `getLenis()` returns the instance for app-owned navigation and lock handling.

Apply `scrollChain` to every nested scroller inside a Lenis page. It scrolls the element until an
edge, then hands the wheel to the page, and stops any page glide in flight when the element takes
the wheel back. Elements that own wheel and pinch input, such as maps, use Lenis's built-in
`data-lenis-prevent` attribute instead.

`@yesid/motion/lenis.css` is the Lenis stylesheet, copied so isolated installs can import it.
`@yesid/ui/base.css` imports it, so an app that imports base.css needs nothing else and drops any
direct `lenis/dist/lenis.css` import.
