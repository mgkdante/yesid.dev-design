`@yesid/i18n-core` adds `createIntl`, which binds each app locale to an Intl tag and returns cached `number`, `dateTime`, `collator` and `plural` Intl objects plus `relativeTime` (a signed offset in seconds read in its largest whole unit, with Intl's own "now" under 5 seconds), and `createCopy`, which returns a `defineCopy` that type-checks every locale against a source locale's keys and signatures. `@yesid/ui/state` adds `clock`, a shared wall clock (1 s tick while subscribed, 30 s under reduced motion, paused in hidden tabs) with a server-time anchor, and `createLocaleContext`. `SiteRoot` takes `lang` and keeps `<html lang>` current after client navigation. A remembered quiet mode now paints right on reload: the head boot script closes every section that follows quiet mode (marked `data-quiet`) before first paint, and `SiteRoot` restores quiet mode before its children render, so they hydrate closed. `@yesid/ui/boot.json`'s hash changes. Importing `@yesid/ui/state` no longer throws where there is no `window` (a node test that loads Svelte's client build); `desktop.current` reads false there. Deprecated: `QuietModeInit.storageKey` and `SiteRootProps.quietModeKey`, because the boot script only reads the standard `quiet-mode` key; a custom key keeps working, but what the boot script paints can disagree with it until hydration. They stay through v0.23.0: removal is no earlier than v0.24.0 and 90 days after this release is published. To migrate, delete local formatter caches, relative-time tables, locale-context code, `<html lang>` effects and clock stores, bind `createIntl`, `createCopy` and `createLocaleContext` once per app, pass `lang` to `SiteRoot`, drop any `quietModeKey`, and take the new `boot.json` hash into a hash-based CSP.
