The brand surfaces move into the packages. `@yesid/ui/brand` adds `TerminalPanel`, the terminal window (signal-head title bar with `title`, `tag`, `status` and an `actions` snippet, a hazard rule, the body and an optional `footer` readout), `CodeBlock`, which shows source in a `TerminalPanel` with the language as its tag and an optional copy button and takes the app's highlighted `<pre>` as `children`, and `ManifestoCanvas`, the circuit-node backdrop of brand headers (static under reduced motion). `ArticleHeader` now renders a `ManifestoCanvas` by default; its `canvas` snippet replaces it, and an empty snippet leaves the header plain. `@yesid/ui/base.css` styles the terminal and code-block classes (`.terminal-*`, in the components layer), so markup rendered on the server can wear the same chrome. `@yesid/ui/blueprints` (new) exports 40 blueprint drawings in `currentColor`, such as `BlueprintBridge` and `BlueprintSignal`; `BlueprintBusSide` takes the fleet's `operator`. `.led-pulse` now stops under reduced motion, as documented. `@yesid/tokens` adds the `syntax` group (`--syntax-keyword`, `-string`, `-number`, `-function`, `-comment`, `-punctuation`, `-plain`), aliases of the brand voices for code highlighting. `@yesid/motion/utils/blueprintScrub` (new) exports `blueprintScrub(band, trigger = band)`, which draws a header's blueprint art as `trigger` scrolls through the viewport; it fits `ListingFrame`'s `onHeaderMount`. To migrate, delete local manifesto canvases and the `canvas` snippets that pass them, local terminal panels and their CSS, code blocks, blueprint scrubs and drawings, import these instead, and color highlighters through `--syntax-*`.

Removed, with the owner's waiver of the 90-day wait (both version gates are met and neither consumer uses them): `@yesid/tokens/generators/theme-block` and its legacy `./src/generators/theme-block.ts` alias (`generateThemeBlock`, `replaceThemeRegion`; deprecated in v0.18.0, use `@yesid/tokens/theme.css` or `generateThemeCss`), `MetroStation`'s `roundel` snippet (deprecated in v0.19.0; the default roundel is the one every product uses), and `QuietModeInit` with its `storageKey` plus `SiteRootProps.quietModeKey` (deprecated in v0.22.0; quiet mode always uses the standard `quiet-mode` key, the one the boot script reads). To migrate, delete any use of them.
