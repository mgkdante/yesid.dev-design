# Support

For questions, use [yesid.dev/contact](https://yesid.dev/contact) or email `contact@yesid.dev`.

Public issues may be used for reproducible defects in a released package. Use the
[bug report form](https://github.com/mgkdante/yesid.dev-design/issues/new?template=bug-report.yml)
and include the release tag from your package URLs, a minimal reproduction, the expected result
and the actual result. A feature request names the products that need it.

Security reports must follow [SECURITY.md](SECURITY.md), not a public issue.
